# 產品層補強檢查清單

在補強 spec.md 的產品面向時，確認以下項目已涵蓋：

## 問題定義

- [ ] 核心問題是否以使用者語言描述（非技術語言）？
- [ ] 「若不解決此問題」的後果是否明確？
- [ ] 目標使用者是否具體（非「所有人」）？

## 功能範圍

- [ ] Must-have 與 Nice-to-have 是否明確分離？
- [ ] 非目標（不做的事）是否明確列出至少 3 條？
- [ ] 功能清單是否按優先順序排列？

## 成功指標

- [ ] 是否有至少一個可量化的成功指標？
- [ ] 成功指標是否在使用者可控範圍內？
- [ ] 是否避免了「使用者滿意」等模糊指標？

## 邊界情況（產品層）

- [ ] 是否定義了使用者輸入不完整時的行為？
- [ ] 是否定義了功能失敗時的使用者體驗？
- [ ] 是否考慮了不同使用者技術程度的差異？
