# Anti-AI-Slop 檢查清單

識別以下典型 AI 生成感的視覺模式，每個「是」都需要改善：

## 過度模板化

- [ ] 是否每個區塊都是「標題 + 副標題 + 三個卡片」的格式？
- [ ] 是否 Hero Section 都是「大標題 + 說明文字 + CTA 按鈕」的固定組合？
- [ ] 是否所有 section 的佈局高度相似（缺乏節奏變化）？

## 過度的視覺裝飾

- [ ] 是否過度使用漸層（gradient）背景？
- [ ] 是否每個元素都有圓角 + 陰影的組合？
- [ ] 是否使用了過多的裝飾性 emoji 或圖示？
- [ ] 是否背景有不必要的幾何圖形或 blob？

## 缺乏視覺層次

- [ ] 是否所有文字大小過於相近（缺乏 H1/H2/Body 的明確差異）？
- [ ] 是否主要 CTA 按鈕和次要連結的視覺權重差異不足？
- [ ] 是否重要資訊和輔助資訊的視覺差異不夠明顯？

## 過於稀疏的佈局

- [ ] 是否頁面有大量空白但沒有內容密度？
- [ ] 是否卡片內容很少但佔用大量空間？
- [ ] 是否文字行長（line-width）過短導致閱讀不順暢？

## 不自然的文案

- [ ] 是否有典型的 AI 行銷文案（「革命性」、「顛覆性」、「強大的」）？
- [ ] 是否有 placeholder 文字未替換（Lorem ipsum 等）？
