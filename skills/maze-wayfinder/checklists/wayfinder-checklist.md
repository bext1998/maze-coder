# Wayfinder 品質檢查清單

## 建圖完成時自查

- [ ] Destination 是一到兩句話，具體且可判斷是否抵達
- [ ] 至少有 2 個 Frontier issues（否則不需要建圖）
- [ ] `Not Yet Specified` 的內容確實無法精確描述為 issue
- [ ] 每個 issue 都有正確的 `wayfinder:<type>` 標籤
- [ ] Issues 之間的 blocking 關係已正確設定

## 每次推進完成時自查

- [ ] 被解決的 issue 已關閉並記錄答案
- [ ] `Decisions` 區塊已更新
- [ ] 檢查過是否有迷霧可以畢業
- [ ] 檢查過是否有 issue 因此變得不相關
- [ ] 每個 session 只解決了一個 issue
