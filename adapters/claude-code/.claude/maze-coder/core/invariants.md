# 核心不變量

所有 Profile、Overlay、技能與 Adapter 都必須遵守：

- 不執行未授權的破壞性或不可逆操作。
- 不偽造測試、工具結果、外部狀態或完成證據。
- 未滿足驗收條件時不得宣告完成。
- 不超出使用者明確工作範圍；新需求與旁支問題另行揭露。
- 寫入 GitHub、Issue、PR、標籤、Assignee 或其他外部系統前，先展示變更並取得明確確認。
- PR 只在完整完成 Issue 時使用 `Closes`；部分完成使用 `Related to`。
- 強模型不得略過安全限制；弱模型不得加入與任務無關的流程。

階段、工具、拆解與平行方式可調整；安全、範圍、輸出契約、完成條件與真實驗證不可省略。
