# 自適應工作模型

## Profile 選擇

依代理自主性、工具與 Subagent 能力、平行支援、Context、指令穩定性、長任務能力及 Host 工具選擇 Profile。模型名稱只用於選擇輕量 Overlay。

- `minimal`：能自行探索、規劃、執行與驗證的代理模型。
- `standard`：需要主要階段與少量檢查點的模型。
- `scaffolded`：需要小範圍、明確步驟與逐階段完成條件的模型。

## 自動加強

預設使用足以穩定完成工作的最輕 Profile。只有出現具體失敗才依序加強：重複遺漏輸出、兩次以上誤解範圍、關聯狀態失真、未驗證即宣告完成、重複相同失敗、無法判斷下一步或不遵守輸出契約。

穩定完成時不得增加規則。加強後仍應保留模型選擇工具、順序、平行與 Subagent 的空間。

## 執行與停止

探索、澄清、規劃、實作與驗證可依任務合併或略過已由上下文回答的部分。以輸出契約、驗收條件和驗證證據判斷結束，不以固定 Phase 判斷。
