# maze-grilling

## 目標
以最少問題取得可推進本輪目標的決策。
## 觸發
僅由 Grill 入口載入。
## 必要輸入
待檢內容、證據與本輪目標；缺少時先推薦目標並確認。
## 核心行為
先自行查證事實；每次只問一個問題並附推薦答案與理由。答案須直接改變方案選擇、工作範圍或非目標、不可逆或高成本決策、驗收條件至少一項；非阻塞問題列入待辦分支。

第 5 題檢查能否決策；每輪預設最多 7 題，使用者可預先另定上限，agent 不得中途延長。到限停止，由使用者決定是否另開一輪。
## 確認點
產品、架構與取捨由使用者決定。
## 輸出契約
進行中每輪一題、推薦答案、理由及受影響分支；結束時摘要已決定、未決分支、推薦預設值及是否需要另一輪 Grill。
## 完成條件
可推進本輪目標且無阻塞分支，或已到上限並摘要。
## 邊界
可查證問題不得詢問；非阻塞分支不得延長 Grill；釐清前不實作。
