# 前端 UX 檢查清單

評估使用者體驗的基本要素：

## 操作流程

- [ ] 主要操作路徑（Happy Path）是否直覺清楚？
- [ ] 次要操作是否不會搶佔主要操作的視覺焦點？
- [ ] 操作的結果是否有明確的反饋（成功 / 失敗訊息）？

## 錯誤處理

- [ ] 錯誤訊息是否用使用者語言說明問題（非技術代碼）？
- [ ] 錯誤訊息是否提供解決方向？
- [ ] 表單驗證是否在適當時機觸發（非只在送出時）？

## 狀態設計

- [ ] Loading 狀態是否有視覺指示？
- [ ] 空狀態（無資料時）是否有設計（非空白頁面）？
- [ ] 成功狀態是否有明確反饋？

## 導航與定位

- [ ] 使用者是否知道自己在哪個頁面？
- [ ] 返回 / 取消操作是否清楚可見？
- [ ] 長頁面是否有回到頂部或目錄導覽？

## 互動設計

- [ ] 可點擊元素是否有 hover 狀態？
- [ ] 按鈕點擊後是否有 disabled 狀態防止重複點擊？
- [ ] 鍵盤操作是否合理（Tab 順序、Enter 送出等）？
