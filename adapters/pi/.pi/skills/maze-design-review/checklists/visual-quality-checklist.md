# 視覺品質檢查清單

評估視覺設計的一致性與品質：

## 字型系統

- [ ] 標題（H1/H2/H3）、本文、說明文字的大小層次是否清楚？
- [ ] 字型粗細（font-weight）是否有效使用來建立層次？
- [ ] 行高（line-height）是否適合閱讀（本文建議 1.5-1.7）？
- [ ] 字體顏色對比度是否足夠（本文在白底建議 #333 以上）？

## 顏色系統

- [ ] 主色（Primary）、次色（Secondary）、強調色是否一致使用？
- [ ] 是否有未統一的顏色值（例如三種不同的灰）？
- [ ] 文字和背景的對比度是否符合基本可讀性？

## 間距系統

- [ ] 是否使用一致的間距單位（例如 4px 的倍數）？
- [ ] 相同層級的元素之間距離是否一致？
- [ ] 元素到容器邊緣的 padding 是否一致？

## 對齊

- [ ] 所有元素是否對齊到明確的網格或基準線？
- [ ] 是否有元素因為特殊處理而破壞對齊感？

## 響應式

- [ ] 在 375px（手機）寬度下是否正常顯示？
- [ ] 在 1280px（桌面）寬度下是否正常顯示？
- [ ] 文字是否在小螢幕上不會過小或被截斷？
