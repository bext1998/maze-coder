# 測試計畫檢查清單

確認測試計畫的完整性：

## 測試覆蓋範圍

- [ ] 每個 Must-have 功能是否有對應的測試案例？
- [ ] 每個 Acceptance Criteria 是否有對應的驗證方式？
- [ ] 是否有「無法測試」的 AC，並說明原因？

## 邊界情況覆蓋

- [ ] 空輸入是否有測試案例？
- [ ] 最大值 / 最小值邊界是否有測試案例？
- [ ] 非預期格式是否有測試案例？
- [ ] 網路 / IO 失敗是否有測試案例（若適用）？

## 測試環境

- [ ] 測試環境是否明確定義（本地 / staging / CI）？
- [ ] 測試資料是否準備好（若需要）？
- [ ] 測試執行者是否清楚（手動 / 自動化）？

## 測試結果記錄

- [ ] 每個測試案例是否有通過 / 失敗的明確記錄？
- [ ] 失敗案例是否有重現步驟？
- [ ] 是否有標記「已知問題不在本次範圍」的測試？
