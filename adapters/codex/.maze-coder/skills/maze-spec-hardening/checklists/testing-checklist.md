# 測試層補強檢查清單

在補強 spec.md 的測試面向時，確認以下項目已涵蓋：

## 驗收標準（AC）

- [ ] 每個 Must-have 功能是否有對應的 AC？
- [ ] 每個 AC 是否有明確的「測量方式」？
- [ ] 每個 AC 是否有明確的「通過門檻」？
- [ ] 每個 AC 是否標記「是否可自動化」？
- [ ] AC 是否避免了「看起來完整」等模糊描述？

## 測試計畫

- [ ] 是否定義了測試層次（結構驗證 / 功能測試 / 整合 / 可攜性）？
- [ ] 每個關鍵測試案例是否有唯一 ID？
- [ ] [FROZEN] 的測試案例是否標記清楚？
- [ ] 是否列出「禁止的測試行為」（如用 `|| true` 忽略失敗）？

## 邊界情況（Edge Cases）

- [ ] 是否涵蓋「在錯誤目錄執行」的情況？
- [ ] 是否涵蓋「中途中斷」的情況？
- [ ] 是否涵蓋 Windows / Linux 跨平台差異？
- [ ] 是否涵蓋非 ASCII 字元（中文、特殊符號）？
- [ ] 是否涵蓋「輸入為空」的情況？
- [ ] 是否涵蓋「重複執行同一操作」（冪等性）？

## 迴歸測試

- [ ] 是否定義了修改核心檔案後的迴歸驗證方式？
- [ ] 迴歸測試是否可自動化執行？
