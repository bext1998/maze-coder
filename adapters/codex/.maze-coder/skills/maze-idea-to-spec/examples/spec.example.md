# TaskFlow CLI 規格書

> 版本：1.0
> 最後更新：2026-05-20
> 狀態：草稿

---

## 1. 專案概述

TaskFlow CLI 是一個終端機任務管理工具，讓開發者在不離開終端機的情況下管理每日任務清單。它解決開發者在 IDE 和瀏覽器之間切換來管理任務的上下文切換問題，目標使用者是習慣終端機工作的個人開發者。

---

## 2. 核心問題

開發者在 coding session 中需要記錄「等等要做的事」，但開啟瀏覽器或 GUI 應用會打斷工作流。大多數 CLI 任務工具要麼功能過於複雜（需要學習成本），要麼太簡單（只是一個 todo.txt）。

---

## 3. 目標

本專案必須達成：

1. 讓使用者在 5 秒內新增一個任務
2. 讓使用者列出、完成、刪除任務
3. 任務持久化存儲（關閉終端機後仍保留）

---

## 4. 非目標

本專案不包含：

- Web 介面或 GUI
- 多人協作或雲端同步
- 重複任務或提醒功能
- 時間追蹤

---

## 5. 功能清單

### Must-have（MVP 必要）

- [ ] `task add "描述"` — 新增任務
- [ ] `task list` — 列出所有未完成任務
- [ ] `task done <id>` — 標記任務完成
- [ ] `task delete <id>` — 刪除任務
- [ ] 任務存儲在 `~/.taskflow/tasks.json`

### Nice-to-have（後續可加）

- [ ] `task list --done` — 列出已完成任務
- [ ] 任務優先級標記

---

## 6. 技術考量

- **語言 / 框架**：Node.js（使用者熟悉 JavaScript）
- **平台**：macOS / Linux，需支援 Windows
- **外部依賴**：盡量不使用第三方套件
- **限制**：安裝方式不得需要 sudo

---

## 7. 成功指標

- `task add "買咖啡"` 可在 2 秒內完成
- 在三個不同 OS 上執行結果相同
- `task list` 輸出清晰、無多餘雜訊
