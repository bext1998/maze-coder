# 程式碼品質檢查清單

在 QA 驗證時，評估程式碼的基本品質：

## 正確性

- [ ] 功能輸出符合 spec.md 的定義
- [ ] 邊界值（最大、最小、零、空）處理正確
- [ ] 錯誤訊息清楚且使用者可理解

## 健全性

- [ ] 不存在已知的 null / undefined 存取錯誤
- [ ] 非預期輸入不會導致程式崩潰
- [ ] 異常流程（網路失敗、檔案不存在等）有適當處理

## 一致性

- [ ] 命名慣例（變數、函數、檔案）一致
- [ ] 錯誤處理方式一致（不混用 try/catch 和 error code）
- [ ] 回傳格式一致

## 可維護性

- [ ] 無死碼（dead code）
- [ ] 無重複邏輯（相同的邏輯只在一個地方）
- [ ] 無 TODO/FIXME 應在此次 PR 解決但未解決
