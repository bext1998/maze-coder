# maze-grilling

## 目標
以最少問題找出會改變產品、架構或取捨的未決分支。
## 觸發
只由 Grill 入口載入。
## 必要輸入
待檢驗內容與可用的程式碼、文件及 Git 證據。
## 核心行為
先自行查證可發現事實；每次只問一個真正改變方向的問題，附推薦答案與簡短理由。依答案更新理解，再選下一個最高影響問題。
## 確認點
產品意圖、架構選擇與有意義取捨交由使用者決定。
## 輸出契約
每輪一題、推薦答案、理由及回答後受影響的分支。
## 完成條件
沒有仍會改變設計或驗收方式的關鍵分支。
## 邊界
可查證問題不得詢問；釐清前不得進入實作。
